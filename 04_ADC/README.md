# 04. ADC

## 🎯 학습 목표
*   **ADC (Analog-to-Digital Converter)**: 외부의 아날로그 전압을 디지털 수치(0~1023)로 변환하여 읽는 법을 배웁니다.

## 🛠 주요 부품
*   가변저항(Potentiometer), 조도센서 등

## 💻 주요 함수 (Arduino)
*   `analogRead(pin)`: 아날로그 핀의 전압을 읽어 0~1023 값으로 반환
