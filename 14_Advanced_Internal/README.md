# 14. Advanced Internal Features

## 🎯 학습 목표
*   MCU의 성능을 극대화하거나 안정성을 높이는 고급 내부 기능들을 다룹니다.

## 💻 주요 주제
*   **Sleep Mode**: 전력 소모를 최소화하여 배터리로 구동하는 장치 개발 기초
*   **Digital Filtering**: 가우스 필터, FIR 필터 등을 이용한 센서 노이즈 제거
*   **Volatile**: 최적화를 방지하여 인터럽트 내 변수를 안전하게 관리하는 법
