# 07. PWM

## 🎯 학습 목표
*   **PWM (Pulse Width Modulation)**: 디지털 신호의 듀티비를 조절하여 아날로그 출력(LED 밝기, 전압 조절)과 유사한 효과를 내는 법을 배웁니다.

## 🛠 주요 부품
*   LED, DC 모터, 부저 등

## 💻 주요 함수 (Arduino)
*   `analogWrite(pin, value)`: PWM 기능을 사용하여 0~255 사이의 출력 (밝기 등 조절)
