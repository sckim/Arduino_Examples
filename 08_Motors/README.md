# 08. Motors

## 🎯 학습 목표
*   다양한 모터의 동작 원리를 이해하고 제어하는 법을 배웁니다.
*   **서보 모터(Servo)**: 지정한 각도로 정밀하게 움직이는 모터 제어
*   **스테핑 모터(Stepper)**: 정해진 단계(Step)만큼 회전시켜 위치를 제어하는 모터 학습

## 🛠 주요 부품
*   SG90 서보 모터, 28BYJ-48 스테핑 모터 및 드라이버(ULN2003)

## 💻 주요 라이브러리/함수
*   `Servo.h`: 서보 모터 제어 표준 라이브러리 (`write(angle)`)
*   `Stepper.h`: 스테핑 모터 제어 표준 라이브러리
