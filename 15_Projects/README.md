# 15. Projects (Extended Examples)

## 🎯 이 폴더의 역할
*   `00~14`의 기본 교과 폴더에서 **대표 예제만 남기고 덜어낸 확장/심화/중복 예제**를 모아둔 곳입니다.
*   폴더 이름은 원래 있던 기본 교과 폴더의 이름 앞에 같은 번호를 붙이고 뒤에 `_Extended`를 붙였습니다 (예: `09_I2C_Communication` → `09_I2C_Communication_Extended`). 어느 챕터에서 나온 예제인지 번호로 바로 알 수 있습니다.
*   기본 교과를 익힌 뒤 더 다양한 변형이나 다른 칩·모듈을 다뤄 보고 싶을 때 참고하세요.

## 📁 특징
*   이 폴더의 예제들은 서로 선행관계가 없어서, 하위 그룹 안의 예제에 남아 있는 숫자 접두사는 **원래 챕터에서의 순서 흔적**일 뿐 학습 순서를 뜻하지 않습니다.
*   특정 제품·연구용 완성 프로젝트와 센서 모듈 모음은 `20_Applications`에 있습니다.
