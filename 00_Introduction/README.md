# Arduino & AVR MCU Learning Curriculum

이 커리큘럼은 아두이노(ATmega328P)를 이용한 임베디드 시스템 학습을 위해 14단계로 구성되었습니다. 기초적인 디지털 입출력부터 고난도의 하드웨어 인터럽트 및 시스템 통합까지 체계적으로 학습할 수 있습니다.

## 📚 학습 단계 안내

1.  **01_Digital_IO**: LED, 버튼 등 기초 디지털 입출력
2.  **02_Serial_Comm**: 시리얼 모니터 디버깅 및 PC 통신
3.  **03_ADC_PWM**: 아날로그 입력(ADC) 및 밝기 제어(PWM)
4.  **04_Segment_Display**: 7-세그먼트(FND) 숫자 표시
5.  **05_Motors**: 서보 및 스테핑 모터 제어
6.  **06_Simple_Sensors**: 직접 신호 방식 센서 (초음파, 네오픽셀 등)
7.  **07_I2C_Devices**: SDA/SCL 방식의 I2C 통신 장치 (LCD, RTC 등)
8.  **08_SPI_Devices**: 고속 SPI 통신 장치 (SD카드, 매트릭스 등)
9.  **09_OneWire_Devices**: 단선 통신 센서 (DHT11, DS18B20)
10. **10_Timers_Counters**: 타이머/카운터를 이용한 정밀 시간 제어
11. **11_Interrupts**: 이벤트 기반의 하드웨어 인터럽트 제어
12. **12_EEPROM_Storage**: 비휘발성 데이터 저장 및 관리
13. **13_Advanced_Internal**: 전력 관리(Sleep) 및 데이터 필터링 기초
14. **14_Integrated_Projects**: 여러 기능을 조합한 종합 시스템 프로젝트

## 🚀 시작하기 전 주의사항

*   **하드웨어 연결:** 각 예제를 실행하기 전 회로도를 반드시 확인하세요.
*   **라이브러리:** 일부 예제는 외부 라이브러리 설치가 필요합니다. (`14_Integrated_Projects`나 `99_Archive`에 포함된 .zip 파일 참조)
*   **디버깅:** 시리얼 모니터(`02_Serial_Comm`)를 적극 활용하여 내부 값을 확인하는 습관을 들이세요.
