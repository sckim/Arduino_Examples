# 코딩 스타일 및 권장 사항 (Coding Best Practices)

명확하고 관리하기 쉬운 코드를 작성하기 위한 기본적인 가이드라인입니다.

## 1. 변수 및 상수 명명 (Naming)

*   **상수(Constants):** 하드웨어 핀 번호나 고정된 값은 `const int`와 함께 **대문자와 언더바(`_`)**를 사용하세요.
    *   예: `const int LED_PIN = 13;`
*   **변수(Variables):** 일반 변수는 **카멜 케이스(camelCase)**를 권장합니다.
    *   예: `int sensorValue = 0;`

## 2. 주석 (Commenting)

*   **헤더 주석:** 파일 상단에 프로젝트명, 작성자, 핀 연결 정보를 적으세요.
*   **설명 주석:** 복잡한 로직이 시작되기 전이나 중요한 줄 옆에 주석을 달아 의도를 설명하세요.

## 3. 코드 구조화 (Structure)

*   **Magic Number 지양:** 코드 중간에 의미 없는 숫자(예: `digitalWrite(7, HIGH);`)를 쓰지 말고, 상수로 이름을 붙여 사용하세요.
*   **함수화:** 반복되는 로직이나 복잡한 연산은 별도의 함수로 분리하여 `loop()`를 깔끔하게 유지하세요.

## 4. 디버깅 습관 (Debugging)

*   문제가 생기면 `Serial.print()`를 사용하여 현재 변수 값이 예상과 같은지 항상 확인하는 습관을 가지세요.
*   `delay()`를 너무 길게 쓰면 프로그램이 멈춘 것처럼 보일 수 있으니 주의하세요.
