# 12. One-Wire Devices

## 🎯 학습 목표
*   **One-Wire**와 같이 고유한 단선 통신 방식을 사용하는 센서들의 특성을 이해합니다.

## 🛠 주요 센서
*   **DS18B20**: 정밀 디지털 온도 센서
*   **DHT11**: 보편적인 온습도 센서

## 💻 특징
*   매우 적은 수의 선으로 통신하지만, 데이터 비트 하나하나의 타이밍을 엄격하게 맞추어야 하는 통신 방식을 배웁니다.
